# Workbench

General-purpose workspace for game mods and other small projects.

## Game mods

- [Streets of Rogue](streets-of-rogue/README.md) — BepInEx 5 plugins, including LargerText and UnlimitedRetries. Built by [Streets of Rogue workflow](.github/workflows/sor-build.yml).
- [Enter the Gungeon](enter-the-gungeon/README.md) — BepInEx 5 mods, currently [Bonus Enemy Hearts v1.0.6](enter-the-gungeon/BonusEnemyHearts/README.md). Built by [Enter the Gungeon workflow](.github/workflows/gungeon-build.yml).

- [Nuclear Throne](nuclear-throne/README.md) — NTT v100.034 [Level Checkpoint v1.3.4](nuclear-throne/LevelCheckpoint/README.md) and [Boss Half Health v1.0.0 Beta](nuclear-throne/BossHalfHealth/README.md); ready-to-load `.mod.gml` scripts (no build needed).

Use **Actions** to run the appropriate game-level build workflow manually. Each workflow also runs when files under its game directory change and produces downloadable plugin artifacts.
