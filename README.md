# Workbench

General-purpose workspace for game mods and other small projects.

## Game mods

- [Streets of Rogue](streets-of-rogue/README.md) — BepInEx 5 plugins, including LargerText and UnlimitedRetries. Built by [Streets of Rogue workflow](.github/workflows/sor-build.yml).
- [Enter the Gungeon — Bonus Enemy Hearts](enter-the-gungeon/BonusEnemyHearts/README.md) — BepInEx 5 plugin v1.0.6, with configurable bonus-heart drop chances, console status and tests. Built by [Gungeon workflow](.github/workflows/gungeon-bonus-hearts.yml).

Use **Actions** to run the appropriate build workflow manually. Each workflow also runs on changes to its own mod files, and produces a downloadable ZIP artifact containing its plugin DLL(s).
